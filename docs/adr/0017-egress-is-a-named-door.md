# ADR-0017: 出网走一扇能说出名字的门

Status: accepted(**观察模式**,尚未执行)
Relates: [ADR-0005](0005-git-broker.md)、[ADR-0011](0011-git-boundary.md)(它们守的是「带回来」那一侧)

## Context

这个平台在**产出怎么出去**上花了很多设计:只能变成分支、经 broker、create-only、
必须有人看过。但**数据怎么出去**没有任何约束——每个 cell 命名空间的
`allow-egress` 是:

```yaml
egress:
  - ports: [53/UDP, 53/TCP]
  - ports: [443/TCP]        # 没有 to:,任意主机
```

**任何 pod 可以往互联网上任何一台机器发 443。**

对普通 SaaS 这个不对称可以接受,因为数据外泄的路径是「有人决定泄密」。
**agent 平台多一条 SaaS 没有的路径**:

```
被投毒的 README / issue / 网页
      ↓  agent 把它当指令
读取 workspace
      ↓  一次 HTTPS 请求
代码 / secret / 上下文 送到任意地方
```

合并闸门守的是 agent 能**带回来**什么;出网守的是它能**送出去**什么。
**这是两个完全不同的安全面**,而后者此前完全敞开。

分支是**被批准的**出口。它从来不是**唯一的**出口。

## Decision

**不是把 443 关掉**——模型 API、git、包管理器天然都要出网。是让出网经过一样
**能说出它允许什么、并记录它做了什么**的东西。

```
agent runtime → egress proxy → { 模型 API · 代码托管 · 已批准的镜像源 · 企业服务 }
```

### 四个设计选择

**① CONNECT 代理,不解密 TLS。** 目标域名从 CONNECT 请求行拿到,足够做策略和
写审计行;字节保持端到端加密。要解密就得往每个沙盒分发 CA,而且平台从此能读
agent 发出的一切——那是另一个量级的决定,做策略和审计用不着。

**② 拒绝 CONNECT 到裸 IP,观察模式下也拒绝。** `CONNECT 203.0.113.7:443`
一行就绕过整个域名白名单。而且放它过去也学不到东西:**一个地址不是任何人事后
能审查的目的地**。

**③ 归因靠客户端 IP,不往 pod 里塞令牌。** ADR-0005 说工作负载不持有任何能跟
控制面说话的凭据,而一个出口令牌恰恰就是那种东西。pod 地址由 CNI 分配、在 pod
内部改不了,控制面本来就知道哪个 pod 属于哪个会话——**身份在控制面侧从工作负载
选不了的东西推出来**。

**④ 先观察,后执行。** 上线即观察模式:全放行、全记录。白名单要从**真实一周的
审计日志里发现**,不是猜。猜错的白名单不会优雅降级——模型调用当场失败,平台停摆。

### 审计行长什么样

```
principal=u-dd7f41d4  cell=demo  session=01m09…  host=api.moonshot.cn
allow=true  rule=api.moonshot.cn  bytes_up=8214  bytes_down=41022
```

这才是企业 agent 平台真正需要的那条链:**人 → 会话 → agent → 目的地**。
它和平台其余部分授权用的是**同一个 principal id**(ADR-0016),所以两边的日志
能放在一起读。

字节数是不解密的前提下唯一的量化信号:「这个会话往一个**允许的**主机发了 300MB」
是个值得问的问题。

## Consequences

**现在**:代理已部署并观察;`NO_PROXY` 排除集群内地址(否则 runtime 连 broker
都会被出口策略拒绝——症状是 git push 失败,而人会去查 broker)。

**还没做,是两步,都不自动**:

1. **收紧 `allow-egress`**:把 443 的无条件放行去掉,只留到代理的 3128。
   在白名单被真实流量验证完整之前不做这一步。
2. **`observe: false`**。

顺序不能反:先关直连、白名单还不全,等于关停平台。

**k3s 用 flannel,NetworkPolicy 只认 IP/CIDR,做不了 FQDN**——这是为什么策略
必须落在代理上而不是网络层。换 Cilium 可以把一部分推回网络层,但归因和审计仍然
要一个能看见域名的东西。

**代理是新的单点。** 一旦第 1 步做完,它挂了所有 agent 就出不了网。这与
「控制面与运行面故障域分离」是同一批要处理的事(ROADMAP P1)。
