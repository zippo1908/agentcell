# AgentCell

**一个给 AI coding agent 用的工作间。** 每个项目一个常驻实例(Cell),里面
每个人一条活会话——自己的 worktree、自己的终端、自己的对话;产出经清算、批阅
才进正式区。

这个 wiki 按「你要办的事」组织。**想先弄懂它是什么,读
[概念模型](Concepts);想让同事用起来,读 [装起来](Install)。**

## 一句话版本

**项目是原子。** 不是任务,也不是会话——一个项目有自己的 git、自己的预览、
自己的正式区;人在里面工作,agent 在里面干活,出口只有一个:清算。
